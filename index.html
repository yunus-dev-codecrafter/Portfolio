About

Practical web development, built to last.

I’m a front-end and PHP web developer based in Kaduna, Nigeria. I build responsive, accessible websites and PHP/MySQL web applications with clean HTML, CSS, JavaScript and PHP.

Most of what I know comes from shipping real projects: a bilingual daily to-do app, an educational platform with a PHP and MySQL backend, and a Quran memorization logbook. Each one taught me how to structure code, work with data, and keep an interface clear on small screens.

I’m growing toward full-stack development, building on the front-end and PHP/MySQL work I already do and adding more Node.js, deeper SQL and React. I enjoy solving problems inside existing codebases as much as starting from scratch, and I care about details: readable markup, honest content, and interfaces that hold up on a phone.

I’m open to suitable opportunities, freelance work and collaboration.

Featured projects

Selected work, with the code public.

01

Fikra To-Do App

A daily to-do app built to solve a small but real problem: a task list that stays clean without manual resets. Tasks persist between visits and reset automatically at midnight, with optional smart reminders, Deen/Work/Study/Personal categories and a Qur’an revision tracker across the 604-page Mushaf. Arabic and English are both supported, and it installs as an offline progressive web app with a service worker and web app manifest.

  • HTML
  • CSS
  • JavaScript
  • PWA

Lisanun Mubeen Academy

An educational platform built with PHP and MySQL. The codebase covers student registration, an admin area, exam results and certificates, and documents Quran memorization features that are still in development. I wrote the backend and front-end and deploy and maintain the site on shared hosting. Parts of the platform are still being built.
